# 06 WorkGraph & Alerts

## Role

The WorkGraph is the real-time operational awareness surface powered by Omni Discovery.

It shows relationships between:

- Systems
- Proof types
- Cryptographic primitives
- Issued receipts
- Migration status
- Human / policy authorities

## 1 Alert Categories

- **P0** — Primitive in active use with imminent or unknown quantum threat and no migration path
- **P1** — High-value receipts still on classical-only (Level 0) proof types
- **P2** — Migration in progress; continuity chain incomplete
- **P3** — Informational / upcoming review required

## 1.1 Executive View

A security officer or executive can open the WorkGraph and immediately answer:

- Which of our critical receipts would break if this algorithm fell tomorrow?
- Which Migration Receipts are still missing?
- What is the current continuity posture of the organization?
